About this project

A home for Pyr knowledge that does not wander off.

The Great Pyrenees Archive is a public site for people who want the history in one sitting, a catalog of the best writing already on the internet, and a working how-to for livestock-guardian raising. Future sections can take health, rescue, and regional working notes without breaking the frame.

How the catalog works

Each entry is a title, source, year if known, topic tag, original summary, and outbound link. We do not reprint other people’s full articles. That keeps us honest and keeps the authors’ sites in the conversation.

New sources are added by appending an object to data/articles.json. Search and filters update themselves.

What comes later

Natural next rooms: coat and climate care, rescue reality versus working homes, predator notes by region, and a reading list that includes books as well as web articles. The bones are already here.

Built as a public GitHub Pages site. Code lives in the great-pyrenees repository.
